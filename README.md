# Botellas

Proyecto para resolver puzzles de movimiento de piezas entre botellas.

Estructura básica:
- `backend/` - Node + Express + TypeORM backend

Instrucciones rápidas:

1. Instalar dependencias backend:

```powershell
cd backend
npm install
```

2. Crear base de datos Postgres (si no existe):

```powershell
node create_db.js
```

3. Ejecutar backend en desarrollo:

```powershell
npm run dev
```

Luego podés continuar el desarrollo en otra máquina clonado este repositorio desde GitHub.
